## arduino-app-cli app ps
A CLI tool to manage Arduino Apps, including starting, stopping, logging, and provisioning.

Usage:
  arduino-app-cli app [command]

Available Commands:
  clean-cache Delete app cache
  destroy     Destroy an Arduino App
  export      Export an existing Arduino App to a zip file
  import      Import an Arduino App from a zip file
  list        List the Arduino apps
  logs        Show the logs of the Python app
  new         Creates a new Arduino App
  restart     Restart or Start an Arduino App
  start       Start an Arduino App
  stop        Stop an Arduino App

Flags:
  -h, --help   help for app

Global Flags:
      --format string      Output format (text, json, json-lines) (default "text")
      --log-level string   Set the log level (debug, info, warn, error) (default "error")

Use "arduino-app-cli app [command] --help" for more information about a command.
